✅ Extract statistical features from ENTIRE signal
✅ Machine learning finds patterns in these features
✅ Compare feature patterns, not raw waveforms

📈 PERFORMANCE METRICS EXPLAINED
================================================================================

FAR (False Accept Rate):
  • How often the system accepts an IMPOSTER
  • Lower is better (security)
  • Sritiz: 12.5% with Gradient Boosting (1 out of 8 imposters got through)

FRR (False Reject Rate):
  • How often the system rejects the GENUINE user
  • Lower is better (usability)
  • Sritiz: 0% with Gradient Boosting (never rejected genuine Sritiz)

Why other models failed:
  • Random Forest, SVM, MLP: FRR = 100%
  • They NEVER accepted genuine Sritiz samples in testing
  • Too conservative / overfitted to training data
  • Impractical for real-world use
